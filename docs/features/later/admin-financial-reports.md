# Admin Financial Reports & Sales Analytics

Status: Done
Priority: Later
Owner: Implemented

## Goal
Give platform administrators complete oversight of global marketplace sales, net platform revenues, instructor earnings liabilities, and payout fulfillment.

## Requirements
- Global financial summary metrics (Gross Merchandise Value, Net Platform Revenue, Instructor Net Earnings, Pending Payouts).
- Monthly sales trends and revenue forecasting charts.
- Top grossing courses and high-earning instructors ranking.
- Payout request moderation (approve/process/reject instructor withdrawals).
- Exportable CSV financial ledger.

## Acceptance Checklist
- [x] Admin financial analytics dashboard with revenue charts and summaries
- [x] Payout moderation workflow with status updates
- [x] Platform sales ledger with filterable dates and payment methods
- [x] Global financial statement CSV export
